# 大人数で泊まる名簿

30〜40人で貸し切れる全国の廃校宿をまとめた1枚もの。
静岡・旧片浜小の「遊んで泊まれる小学校 カタショー」に泊まったのがきっかけで、
次回の候補を探すために作った。

- 公開URL: https://lazyturtle0852.github.io/haiko-stay/
- 収録: 廃校15件＋校舎じゃない宿6件＋番外3件
- 絞り込み: 地域 / 40人以上OK / 体育館あり / 1日1組貸切

定員・料金は2026年9月時点の公開情報にもとづく暫定値。予約前に各施設の公式サイトで確認すること。

## 構成

- `index.html` — 単一ファイル。施設データは末尾の `DATA` 配列にある。

施設を足すときは `DATA`（廃校）または `DATA2`（校舎以外）に1件追加するだけでカードと絞り込みに反映される。
